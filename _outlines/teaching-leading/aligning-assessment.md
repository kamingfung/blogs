**Promise:** Check that each outcome has a task that asks for the same action at the same level, and spot the outcomes that nothing assesses.

**Trap:** A test is aligned if it covers what was taught; in fact it is aligned only if it asks students to do what the outcome says, at the level the outcome says.

**Assumes:** teaching-leading/writing-learning-outcomes.

## Outline

1. **Three things that must agree**: the outcome, the task that gives evidence of it, and the activity that practices it; describe the idea, then name it as constructive alignment `[verify]`.
2. **The level mismatch**: an outcome asks students to design, and the exam asks them to recall; show why students learn to the test, not to the outcome.
3. **An alignment grid**: outcomes as rows, tasks as columns; an empty row is an untested outcome, an empty column is a task that tests nothing you promised.
4. **Choosing a task that fits the verb**: which kinds of task can show explanation, application, analysis and design; why some outcomes need a project, not a question.
5. **What this means for you**: build the grid for one existing course or training, fix the worst empty row first, and drop one task that serves no outcome.

## Key takeaways

- Students study for the assessment, so a misaligned assessment teaches the wrong thing `[verify]`.
- Every outcome needs at least one task that asks for its exact verb; an outcome with no task is a wish.
- A task that maps to no outcome either reveals a missing outcome or should be cut.
- An alignment grid on one page finds most mismatches before the course runs.
