**Promise:** Write a rubric that describes what good work looks like before the work is done, and share it so learners can use it to judge their own drafts.

**Trap:** A rubric is a grader's tool to score faster; its larger value is as a description of quality that learners see before they start.

**Assumes:** Nothing required; it uses the outcomes and tasks from teaching-leading/writing-learning-outcomes and teaching-leading/aligning-assessment.

## Outline

1. **Criteria and levels**: a rubric names the qualities that matter and describes each at a few levels; the descriptions, not the points, carry the meaning.
2. **Analytic, holistic and single-point**: describe each shape and when it fits; a single-point rubric describes only the target and leaves room for comments `[verify]`.
3. **Writing level descriptions**: describe what is present at each level, not "good", "better", "best"; avoid counting errors as the only measure.
4. **Rubrics for learners**: hand it out with the task, ask learners to self-assess a draft, and use it to frame feedback.
5. **What this means for you**: write a three-criterion single-point rubric for one task, give it out with the task, and ask for a self-assessment with the draft.

## Key takeaways

- Write the rubric before the task and give it to learners with the task.
- Describe what is present at each level; "good" and "excellent" tell a learner nothing.
- Three to five criteria per task keep a rubric usable `[verify]`.
- Self-assessment against a shared rubric improves drafts before the teacher sees them `[verify]`.
