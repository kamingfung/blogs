**Promise:** Turn a job description into an interview rubric: the outcomes the role needs, one question or task per outcome, and anchored scores each interviewer fills in before any discussion.

**Trap:** Experienced interviewers can sense talent in a free conversation; in fact an unstructured chat mostly measures how much the candidate resembles the interviewer.

**Assumes:** teaching-leading/rubrics.

## Outline

1. **An interview is an assessment**: the same backward-design question applies: what must this person be able to do in the role, and what task would show it.
2. **From job description to criteria**: cut the wish list down to the few outcomes that decide success; write each as an observable behavior, not a trait.
3. **One task per criterion, same task for every candidate**: structured questions or work samples that look like the real job, the hiring version of an authentic task.
4. **Score alone, then talk**: each interviewer scores against written anchors before the debrief, so the first or loudest opinion does not set everyone's score.
5. **What this means for you**: a checklist for your next opening: criteria list, question bank mapped to criteria, anchored score sheet, independent scoring, and a debrief that starts from the sheets.

## Key takeaways

- Structured interviews, with the same questions and a scoring guide for every candidate, predict job performance better than unstructured ones [verify].
- A work sample that mirrors a real task in the role tells you more than a question about how the candidate would do that task [verify].
- Interviewers who write scores before the debrief disagree more openly and anchor less on the first speaker than interviewers who discuss first [verify].
- A criterion you cannot attach to an interview task is not being assessed; drop it or add a task for it.
- Writing anchored descriptions for a low, middle and high score takes less time than one debrief spent arguing about what "strong" means.
