**Promise:** Run a recurring one-on-one as a formative check for both people: the report sets the agenda, and each meeting changes something you do next.

**Trap:** A one-on-one is a status update with the manager; status belongs in a written update, and the meeting is for what writing cannot carry.

**Assumes:** teaching-leading/formative-assessment.

## Outline

1. **What the meeting is for**: blockers, priorities, growth and how the work feels; status goes in writing so the time is free for the rest.
2. **The report owns the agenda**: a shared running document where both people add items during the week; the manager's items go last.
3. **Formative both ways**: the manager checks understanding of goals and load; the report gives the manager feedback; both leave with one change.
4. **Rhythm and protection**: a regular slot that is rarely canceled; moving it is fine, dropping it says the person is a low priority.
5. **What this means for you**: start a shared agenda document with each report, ask them to add the first item, and end each meeting by writing down one agreed change.

## Key takeaways

- Move status into writing so the one-on-one holds what writing cannot.
- Let the report set the agenda; the manager's items go last.
- End each one-on-one with one written change that one of you will make.
- A one-on-one that is often canceled tells the report where they rank.
