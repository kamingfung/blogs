**Promise:** Explain why a learner can hold only a few new pieces at once, and redesign an explanation, slide or document to cut the load that does not help learning.

**Trap:** More information, more detail on the slide and more ways of saying it help understanding; in fact working memory for new material is small, and every extra element competes with the one that matters [verify].

**Assumes:** Nothing in the series file; reads best after teaching-leading/memory-and-spacing.

## Outline

1. **A small workbench**: new information is processed in a working memory that holds only a few items at a time [verify]; long-term knowledge is what lets experts handle more.
2. **Load that helps and load that does not**: the difficulty of the material itself versus the difficulty added by poor presentation; one theory names these intrinsic and extraneous load [verify].
3. **Cutting the load you add**: put labels next to what they label, do not narrate text the audience is also reading, remove decoration [verify].
4. **What works for novices fails for experts**: worked examples help beginners and slow down experts, so support should fade as skill grows [verify].
5. **What this means for you**: review one slide or page: count the new elements, remove what the point does not need, and place each label where the eye already is.

## Key takeaways

- A learner new to a topic can work with only a few new elements at once, so a slide with many unfamiliar elements is not read [verify].
- Placing a label next to the thing it labels, instead of in a separate legend, reduces the effort needed to read a figure [verify].
- Reading text aloud while the same text is on screen tends to hurt comprehension compared with either one alone [verify].
- Step-by-step worked examples help beginners more than problem solving, but the advantage reverses as learners gain expertise [verify].
